# Быстрый запуск SparkPanel Release 1.0.0

## Вариант 1: Docker Compose (полный функционал)

Нужен установленный и запущенный Docker (на Windows/macOS — Docker Desktop).

```bash
cp .env.example .env
docker compose up -d --build
```

Откройте **http://localhost:5000**. Будут запущены панель и PostgreSQL; локальный Docker автоматически добавится как нода «Local».

## Вариант 2: режим разработки

Нужны Node.js 20.12+ и запущенный Docker.

```bash
npm install
npm run dev
```

Панель: **http://localhost:5000**. Без `DATABASE_URL` данные сохраняются в `./data/storage.json` и переживают перезапуск.

## Вход

- **Логин:** `adplayer`
- **Пароль:** `0000`

Смените пароль в разделе «Аккаунт» (Account) сразу после входа — там же можно включить вход с кодом из Google Authenticator (2FA). Язык интерфейса (RU/EN) переключается кнопкой в шапке и на странице входа.

## Первый сервер

1. «Серверы» → «Новый сервер» (Servers → New server), выберите игру, ноду «Local», порт и лимиты.
2. Нажмите «Запустить» (Start). При первом запуске скачивается образ игры — это может занять несколько минут, прогресс виден по статусу «Starting».
3. Вкладка «Консоль» — вывод сервера и отправка команд; «Файлы» — файлы, архивы и редактор конфигов; у Minecraft ещё «Игроки» и «Плагины и моды»; «Бэкапы», «Порты» (и домены), «SFTP», «Переменные», «База данных», «Git», «Настройки» — остальное управление.

## Если Docker не запущен

Панель откроется, но нода будет «offline», и запуск серверов вернёт ошибку «Node is offline». Запустите Docker — статус ноды обновится автоматически в течение 30 секунд.

## Порт 5000 занят?

```bash
PORT=8080 npm run dev
```

Для Docker Compose задайте `PANEL_PORT=8080` в `.env`.

## Остановка

`Ctrl+C` для `npm run dev` или `docker compose down`. Игровые серверы — это отдельные контейнеры и продолжают работать; остановите их из панели.
