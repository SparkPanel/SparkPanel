# SparkPanel

Панель, в которой удобно держать игровые серверы, ботов и небольшие сайты. Каждый сервер живёт в своём Docker-контейнере: упал один — остальные работают дальше, переставили образ или порт — мир и файлы на месте.

**Версия: Release 1.0.0**

## Что умеет

**Серверы.** Minecraft «из коробки»: Vanilla, Paper, Purpur, Fabric, Forge, NeoForge, Quilt или свой JAR. Ядро и нужная Java скачиваются сами — достаточно выбрать тип и версию. Для CS2, Rust, ARK, Valheim, Terraria и Garry's Mod при создании сразу выбирается ядро и настройки именно этой игры — по документации их серверов:
  - **Counter-Strike 2** — режим (соревновательный, обычный, напарники, бой насмерть, гонка вооружений), карта, игроки, пароль, токен Steam (GSLT);
  - **Rust** — ядро Vanilla или Oxide (uMod), размер и сид карты, своя карта по ссылке, игроки;
  - **ARK: Survival Evolved** — карта, пароль, моды Workshop по ID, кроссплей, BattlEye;
  - **Valheim** — ядро Vanilla, BepInEx или Valheim Plus, мир, обязательный пароль, видимость в списке, кроссплей, администраторы;
  - **Terraria** — ядро Vanilla или TShock, мир (имя, размер, сид), игроки, пароль, сообщение дня;
  - **Garry's Mod** — Sandbox, TTT или свой режим, карта, коллекция Workshop, пароль, GSLT.

  Вкладка «Игроки» есть у каждой игры: в CS2, Rust, ARK и Garry's Mod — кто в сети, кик, бан, разбан по SteamID и сообщение в чат через RCON (в CS2 без плагина администрирования доступен только кик); в Terraria — те же действия через консоль сервера; в Valheim, где RCON нет, — списки администраторов, банов и разрешённых игроков. Каталоги модов: плагины uMod для Rust с ядром Oxide (подхватываются без перезапуска) и моды Thunderstore для Valheim с BepInEx — вместе с зависимостями. Моды ARK и коллекции Garry's Mod задаются ID из Steam Workshop в настройках.

  Порты (игровой, query, RCON) и рекомендуемые ресурсы подставляются сами, пароль администратора (RCON) панель задаёт сама и никому не показывает. На странице сервера — адрес и как подключиться в этой игре. Остальные параметры игры — в её конфигах на вкладке «Файлы» и в дополнительных аргументах запуска.

**Не только игры.** Тип «Custom» — это каталог сред: Java, Python, Node.js, PHP, статический сайт, Go, .NET, чистый Ubuntu/Debian или любой образ с Docker Hub. Telegram-бот на Python поднимается так: создали сервер, загрузили `main.py` и `requirements.txt`, нажали «Запустить».

**Управление.**
- Консоль в браузере с цветами (ANSI): живой вывод, команды прямо в процесс, история по стрелкам ↑/↓.
- Файловый менеджер: редактор с подсветкой синтаксиса, перетаскивание файлов, поиск по имени во всех подпапках, упаковка в .zip и распаковка .zip / .tar / .tar.gz. Работает и у выключенного сервера.
- SFTP для каждого сервера, если удобнее FileZilla или WinSCP.
- Переменные окружения (токены ботов, пароли) — секретные значения после сохранения не показываются.
- Резервные копии в один клик, расписание на странице сервера, автоочистка старых и копия во внешнее S3-хранилище (AWS S3, Cloudflare R2, Backblaze B2, Wasabi, MinIO).
- Перезапуск после падения (с лимитом попыток) и уведомления в Discord и Telegram: сервер упал, перезапущен, бэкап не создан, диск почти полон, нода пропала.
- Графики нагрузки за 24 часа и 7 дней, лимиты CPU, памяти и диска.
- Деплой из Git: подключили репозиторий — код обновляется кнопкой или вебхуком GitHub / GitLab / Gitea при каждом push.
- Обновление образа сервера одной кнопкой, копия сервера (с файлами или без), шаблоны для быстрого создания, массовый запуск / остановка / перезапуск.
- Своя база данных для сервера — PostgreSQL или MariaDB в отдельном контейнере, доступна только этому серверу.
- Домены с HTTPS для сайтов: сертификат Let's Encrypt выпускается и продлевается сам.

**Minecraft.** Игроки онлайн, белый список, операторы, баны и кик прямо из панели. Каталог плагинов и модов Modrinth: показываются только совместимые с ядром и версией сервера, файл проверяется по контрольной сумме.

**Несколько машин.** Docker на сервере с панелью подключается сам. Новая машина подключается одной командой (Docker и TLS настраиваются сами), серверы можно переносить между нодами вместе с данными. Для каждой ноды можно задать диапазон портов — новые серверы получают свободный порт автоматически.

**Команда.** Пользователи с точными правами (28 галочек), доступ только к нужным серверам, временный доступ и двухфакторный вход через Google Authenticator или любое другое приложение-аутентификатор: отсканировали QR-код — и без телефона в аккаунт не войти. На случай потери телефона есть одноразовые коды восстановления, а администратор может сбросить 2FA другому пользователю. Владелец сервера может дать доступ к нему другим пользователям с отдельным набором прав только на этот сервер.

**Хостинг.** Квоты: пользователь сам создаёт серверы в пределах выданных лимитов. Оплаченный срок и приостановка сервера — вручную или из своего биллинга через API. Публичная страница `/status` с состоянием выбранных серверов и числом игроков. Интерфейс на русском и английском (переключатель в шапке).

**Автоматизация.** API-ключи для своих скриптов и ботов, плагины на JavaScript, Python и Java ([как писать плагины](PLUGINS_README.md)).

**Защита.** Встроенный фильтр флуда для самой панели плюс пошаговые инструкции для Cloudflare и TCPShield прямо в интерфейсе.

## Установка за пять минут (Docker Compose)

Нужен Linux-сервер (Ubuntu 20.04+ или Debian 11+).

**1. Docker**

```bash
curl -fsSL https://get.docker.com | sudo sh
sudo systemctl enable --now docker
```

**2. Панель**

```bash
sudo git clone https://github.com/SparkPanel/SparkPanel.git /opt/SparkPanel
cd /opt/SparkPanel
sudo cp .env.example .env
sudo nano .env
```

В `.env` обязательно поменяйте `POSTGRES_PASSWORD` и `ADMIN_PASSWORD`. `SESSION_SECRET` можно не трогать, панель создаст его сама.

**3. Запуск**

```bash
sudo docker compose up -d --build
```

Откройте `http://IP_сервера:5000` и войдите. По умолчанию логин `adplayer`, пароль `0000`, или то, что вы указали в `ADMIN_USERNAME` / `ADMIN_PASSWORD`. Пароль лучше сменить сразу — в разделе «Account», там же включается 2FA.

Поднимутся два контейнера: `sparkpanel` (панель) и `sparkpanel-db` (PostgreSQL). Панель управляет Docker хоста через `/var/run/docker.sock`, поэтому игровые серверы запускаются рядом, как обычные контейнеры, и их порты открываются прямо на сервере.

### Обновление

```bash
cd /opt/SparkPanel
sudo git pull
sudo docker compose up -d --build
```

Данные при обновлении не теряются. Настройки и бэкапы лежат в томах `panel-data`, `panel-plugins` и `db-data`, а файлы серверов — в отдельных томах `sparkpanel-<id>-data`.

### Полезные команды

```bash
sudo docker compose logs -f panel     # логи панели
sudo docker compose restart panel     # перезапуск
sudo docker compose down              # остановить панель (серверы продолжат работать)
```

## Без Docker для самой панели (Node.js + systemd)

Если хочется запускать панель напрямую: Docker на машине всё равно нужен, в нём работают серверы.

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs git
curl -fsSL https://get.docker.com | sudo sh

sudo git clone https://github.com/SparkPanel/SparkPanel.git /opt/SparkPanel
cd /opt/SparkPanel
sudo cp .env.example .env && sudo nano .env
sudo npm ci
sudo npm run build
```

Без `DATABASE_URL` всё хранится в файле `data/storage.json`. Если указать PostgreSQL, таблицы создадутся сами при первом запуске.

Сервис `/etc/systemd/system/sparkpanel.service`:

```ini
[Unit]
Description=SparkPanel
After=docker.service network-online.target
Requires=docker.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/SparkPanel
EnvironmentFile=/opt/SparkPanel/.env
Environment=NODE_ENV=production
ExecStart=/usr/bin/node /opt/SparkPanel/dist/index.js
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now sparkpanel
sudo journalctl -u sparkpanel -f
```

`npm start` тоже работает: панель сама читает `.env` из своей папки.

## Домены и HTTPS для серверов

На вкладке «Порты» сервера можно добавить домен: направьте его A-запись на IP ноды, и прокси Caddy на ноде получит сертификат Let's Encrypt и будет передавать запросы на порт сервера. Порты 80 и 443 на ноде должны быть свободны. Почту для Let's Encrypt укажите в «Настройки» → «HTTPS».

## Масштабирование сайтов

Сайты, API и боты (серверы типа «Свой») можно запустить несколькими копиями — вкладка «Масштабирование» на странице сервера:

- **Копии.** Каждая копия — такой же контейнер с теми же файлами, образом и переменными, на любой ноде. Файлы копируются с основного сервера; кнопка «Обновить файлы в копиях» и деплой из Git раскладывают изменения по копиям по очереди, без остановки сайта.
- **Балансировка.** Трафик домена Caddy распределяет между всеми копиями (наименее загруженная получает запрос). Упавшая копия выводится из ротации, а запрос повторяется на другой — посетитель ошибки не видит.
- **Общая база.** Если у сервера есть база данных, все копии подключаются к ней (`DATABASE_URL`, `DB_HOST` и другие переменные задаются сами).
- **Автомасштабирование.** Когда средняя загрузка CPU копий держится выше порога, добавляется копия; когда нагрузка спадает — лишняя убирается (в пределах «не меньше / не больше»). Упавшие копии запускаются снова, копии останавливаются и запускаются вместе с сервером.

Для копий на других машинах у нод должен быть задан публичный адрес («Ноды» → «Адрес и порты»). Порт базы при масштабировании открывается на её ноде; закройте его файрволом для всех, кроме нод панели.

## Домен и HTTPS для самой панели через nginx

```nginx
server {
    listen 80;
    server_name panel.example.com;
    client_max_body_size 512m;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 3600s;
    }
}
```

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
sudo certbot --nginx -d panel.example.com
```

Затем добавьте в `.env` и перезапустите панель:

```env
FORCE_HTTPS=true
TRUST_PROXY=1
```

`TRUST_PROXY` говорит панели, сколько прокси стоит перед ней. Тогда в журнале и в защите от флуда видны настоящие IP посетителей. Если перед nginx есть ещё и Cloudflare (оранжевое облако), прокси два, ставьте `TRUST_PROXY=2`. Без прокси эту переменную не задавайте, иначе любой сможет подделать свой IP.

## Защита от DDoS

На странице «Anti-DDoS» есть три вещи:

- **Встроенная защита панели**: лимиты запросов и соединений, фильтр ботов, проверка «вы не робот». Защищает саму панель, игровые порты она не прикрывает.
- **Cloudflare** бесплатно защищает HTTP/HTTPS, то есть панель за nginx. Игровой порт через оранжевое облако работать не будет. Minecraft можно спрятать за Spectrum (платное дополнение к тарифам Pro/Business), другие игры — только на Enterprise.
- **TCPShield** бесплатно защищает Minecraft Java. API для просмотра сетей прямо из панели доступен с тарифа Pro.

Важная ловушка: **ufw не закрывает порты Docker-контейнеров**. Docker пропускает трафик раньше, чем его видит ufw. Разрешать доступ к игровому порту только с адресов защиты нужно в цепочке `DOCKER-USER`. Готовые команды с актуальным списком IP TCPShield есть в инструкции на той же странице.

## Ноды

Docker на машине с панелью добавляется сам как нода **Local**.

**Одной командой (Linux с systemd).** «Ноды» → «Установить командой» → введите название → выполните показанную команду от root на новой машине:

```bash
curl -fsSL 'https://panel.example.com/api/nodes/install.sh?token=…' | sudo bash
```

Скрипт ставит Docker (если его нет), создаёт на машине ключ и запрос на сертификат (ключ не покидает машину), панель подписывает его своим центром сертификации, и Docker начинает слушать порт 2376 только для клиентского сертификата панели. Команда одноразовая и действует 24 часа. Если у машины несколько адресов, задайте нужный: `SPARKPANEL_NODE_IP=1.2.3.4 bash`. Машина должна видеть панель по адресу из команды, а панель — порт 2376 машины.

**Вручную.** Поставьте Docker и откройте Docker API по TLS (порт 2376) с клиентскими сертификатами `ca.pem`, `cert.pem`, `key.pem` на машине с панелью (папка `DOCKER_CERT_PATH`, по умолчанию `DATA_DIR/docker-certs`). Порт 2375 без шифрования годится только внутри закрытой сети или VPN. Затем добавьте ноду с IP и портом.

**Диапазон портов.** Кнопка «Порты» у ноды: новые серверы получают первый свободный порт диапазона, порты вне его не принимаются.

Порты серверов и SFTP открываются на той ноде, где работает сервер, — не забудьте про фаервол.

## Что где лежит в Docker

| Что | Зачем |
|-----|-------|
| `sparkpanel-<id>` | контейнер сервера |
| `sparkpanel-<id>-data` | том с файлами сервера |
| `sparkpanel-companion-<id>` | служебный контейнер (Alpine + OpenSSH): файлы, бэкапы, SFTP |
| `sparkpanel/companion:2` | его образ (с git, zip, unzip), собирается на ноде автоматически |
| `sparkpanel-db-<id>`, `sparkpanel-<id>-db`, `sparkpanel-net-<id>` | база данных сервера, её том и частная сеть сервера с базой |
| `sparkpanel-proxy`, `sparkpanel-proxy-data` | прокси Caddy для доменов (порты 80/443) и его сертификаты; есть только на нодах с доменами |
| `sparkpanel/certgen:1` | OpenSSL для выпуска сертификатов нод, собирается на машине с панелью |

Если поменяли образ, порты, лимиты или команду запуска, изменения применятся при следующем запуске. Панель подскажет надписью «restart to apply».

## API

```bash
curl -H "X-API-Key: sp_ваш_ключ" https://panel.example.com/api/servers
curl -X POST -H "Authorization: Bearer sp_ваш_ключ" https://panel.example.com/api/servers/<id>/start
curl -X POST -H "X-API-Key: sp_ваш_ключ" -H "Content-Type: application/json" \
     -d '{"command":"say Привет"}' https://panel.example.com/api/servers/<id>/command
```

Биллинг может продлевать и приостанавливать серверы ключом с правом `servers.manage`:

```bash
curl -X PUT -H "X-API-Key: sp_ваш_ключ" -H "Content-Type: application/json"      -d '{"paidUntil":"2026-12-31T23:59:59Z","suspended":false}' https://panel.example.com/api/servers/<id>/billing
```

Когда срок проходит, сервер останавливается и не запускается до продления.

Ключ создаётся в разделе «API» и показывается один раз, панель хранит только его хеш. У ключа есть только отмеченные права, и не больше, чем у его владельца. Полный список запросов, нужные права и коды ответов — на вкладке «Документация» там же.

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|-----------|--------------|------------|
| `PORT` | `5000` | порт панели |
| `HOST` | `0.0.0.0` | адрес, на котором слушает панель |
| `DATABASE_URL` | — | PostgreSQL; без неё данные хранятся в файле |
| `DATA_DIR` | `./data` | бэкапы, настройки, файловое хранилище |
| `PLUGINS_DIR` | `./plugins` | папка плагинов |
| `SESSION_SECRET` | создаётся сам | секрет для cookie-сессий |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | `adplayer` / `0000` | первая учётная запись |
| `FORCE_HTTPS` | `false` | secure-cookie для работы через HTTPS |
| `TRUST_PROXY` | — | сколько прокси перед панелью (`1` за nginx, `2` за Cloudflare + nginx) |
| `ALLOWED_ORIGINS` | — | CORS: домены через запятую |
| `DOCKER_HOST` | стандартный сокет | адрес локального Docker |
| `DOCKER_CERT_PATH` | `DATA_DIR/docker-certs` | TLS-сертификаты для удалённых нод (туда же их кладёт установка нод командой) |
| `UPLOAD_MAX_MB` | `512` | максимальный размер загружаемого файла |
| `SFTP_PORT_START` | `2022` | с какого порта выдавать SFTP-порты |
| `PYTHON_BIN` / `JAVA_BIN` | `python3` / `java` | интерпретаторы для плагинов |

## Если что-то не так

- **Нода «offline».** Проверьте `docker ps` на ноде и доступ к сокету: `ls -l /var/run/docker.sock`. Для удалённой ноды проверьте, открыт ли порт Docker API с машины панели.
- **Сервер в статусе «Error».** Причина почти всегда видна в консоли сервера. Чаще всего это занятый порт, не скачавшийся образ или ошибка в команде запуска.
- **Не пускает после включения HTTPS.** Нужны `FORCE_HTTPS=true` и `TRUST_PROXY=1`. Если панель открывается по обычному HTTP, `FORCE_HTTPS` должен быть `false`.
- **Порт 5000 занят.** Поменяйте `PANEL_PORT` (Docker Compose) или `PORT`.
